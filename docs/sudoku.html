How it Works

Backtracking Algorithm

This solver uses a classic depth-first backtracking algorithm:

  1. Find an empty cell
  2. Try numbers 1-9 that don't violate Sudoku rules
  3. Recursively solve the rest
  4. If no number works, backtrack and try a different number

Time complexity: O(9^n) worst case, but solves typical puzzles in < 10ms.
